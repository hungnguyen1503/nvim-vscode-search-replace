1. Introduction                                  *vscode-search-replace-intro*

`nvim-vscode-search-replace` brings the VS Code search & replace panel to
Neovim: a floating two-column UI with live debounced ripgrep results, inline
red/green diff previews for every match, and a byte-exact Replace All. Built
on <https://github.com/grapp-dev/nui-components.nvim>.

  - live results while you type (ripgrep, debounced)
  - inline old/new diff preview per match, with `\1`–`\9` capture references
  - inline `ab` whole-word, `Aa` case and `.*` regex toggles on the search
    row, plus a Files-to-Include path/glob filter
  - the float opens search-only; pressing the `⇄` box (left of the pattern
    field) reveals the replace row — replace field, `AB` preserve-case box
    and the `⇉` Replace All icon box — the search box keeps a fixed width
  - every box, field and button is mouse-clickable: click a field to type,
    click a box to toggle it, click `Yes`/`No` in the confirmation dialog
  - whole-project, current-file and word/visual-selection search variants
  - `<CR>` jumps to the match, `<C-R>` replaces everywhere after a Yes/No
    confirmation dialog
  - `Alt+h/j/k/l` + `Tab` panel navigation and `Alt+c/w/r/p` hotkeyed
    toggles; the plugin ships no global keymaps
  - `?` in normal mode shows the keymap help overlay

2. Requirements                              *vscode-search-replace-requirements*

  - Neovim >= 0.10 (`vim.uv`, `vim.system`, `vim.base64`)
  - ripgrep (`rg`) on your `PATH`
  - a Nerd Font for the tree icons (optional; UI degrades gracefully)

3. Installation                              *vscode-search-replace-installation*

With lazy.nvim: >lua

    {
      "hungnguyen1503/nvim-vscode-search-replace",
      dependencies = { "grapp-dev/nui-components.nvim", "MunifTanjim/nui.nvim" },
      cmd = "SearchReplace",
      keys = {
        { "<leader>S", function() require("vscode-search-replace").open() end, desc = "Search & Replace" },
        { "<leader>sw", mode = { "n", "v" }, function() require("vscode-search-replace").open({ word = true }) end, desc = "Search word under cursor / selection" },
        { "<C-F>", function() require("vscode-search-replace").open({ file = true, word = true }) end, desc = "Search word under cursor in current file" },
      },
      opts = {},
    }
<
The plugin defines no keymaps by itself; the `keys` block above is the
recommended wiring.

4. Configuration                            *vscode-search-replace-configuration*

                                                    *vscode-search-replace-setup()*
>lua
    require("vscode-search-replace").setup({
      position = "center",
      width = 0.9,
      height = 0.85,
      debounce = 300,
    })
<

position *vscode-search-replace-position*
    Float anchor: `"center"` | `"top"` | `"bottom"` | `"left"` | `"right"`.
    Anything else warns via |notify| and falls back to `"center"`.

width     *vscode-search-replace-width*
    `<= 1`: fraction of the editor columns. `> 1`: absolute column count
    (clamped to the editor width). Default `0.9`.

height   *vscode-search-replace-height*
    Same rule for editor lines. Default `0.85`.

debounce *vscode-search-replace-debounce*
    Milliseconds after the last keystroke before re-searching. Default `300`.

5. Usage                                              *vscode-search-replace-usage*

:SearchReplace                                                *:SearchReplace*
    Open the search & replace float (whole project = cwd).

Keys inside the float: ~
    Key             Action
    <Tab>/<S-Tab>   next / previous panel (focus order below)
    <Esc>/<Esc>     close (first <Esc> leaves insert mode in a focused input)
    q               close (normal mode)
    <CR>            activate the focused widget · jump to the selected match
    click           same as <CR>/Space on boxes and fields; focuses inputs
    <C-R>           Replace All — opens a Yes/No confirmation dialog
    Alt+c           toggle `Aa` match case
    Alt+w           toggle `ab` whole word
    Alt+r           toggle `.*` regular expression
    Alt+p           toggle `AB` preserve case (replace mode only)
    Alt+h/Alt+l     move to the previous/next panel column
    Alt+j/Alt+k     move to the next/previous panel in a column
    ?               show/hide the keymap help overlay (or press the ? box)

    The toggle boxes fill (reverse video) while their option is active.
    Focus order: `⇄` -> Search -> `ab` -> `Aa` -> `.*` -> `?` -> Replace
    input -> `AB` -> `⇉` -> Files to Include -> results tree. The Replace
    row is hidden (not focusable, and `AB` cannot take effect) while the
    `⇄` box is inactive; pressing it (`Enter`/`Space`/click) shows it,
    pressing again hides it — and hides `AB` with it. The search box never
    resizes between modes.

Replace All confirmation: ~
    `⇉` or `<C-R>` first floats a modal dialog asking "Replace N matches in
    M files?". Answer with `y`/`Y` or `<CR>` (yes), `n`/`N`/`q`/`<Esc>` (no),
    or by clicking the `Yes` / `No` boxes. Nothing is written before you
    confirm; the dialog never touches files by itself.

Preserve case (`AB`): ~
    When active, every replacement re-cases itself to the text it replaced:
    an ALL-CAPS match gets an ALL-CAPS replacement, a Title-case match a
    Title-case one (`foo` -> `bar`, `FOO` -> `BAR`, `Foo` -> `Bar`);
    mixed-case matches are replaced verbatim. The replacement's own
    case-code escapes (`\u`, `\U`, `\l`, `\L`) are not applied while `AB`
    is on — the match decides the case. A bare `&` or `%` in the
    replacement is literal in both modes.

Search fields: ~
    Search              ripgrep pattern (literal unless `.*` is on)
    ⇄ / ?              replace-mode / keymap-help boxes flanking the row
    ab                  whole-word toggle box (right of Search): matches are
                        wrapped in keyword boundaries — the same semantics as
                        `rg --word-regexp`; `\1`–`\9` stay unshifted
    Aa / .*             case sensitivity / regex toggles
    Replace             replacement text; `\0`–`\9` are capture references in
                        regex mode. Empty → no diff preview, Replace All is a
                        no-op.
    AB                  preserve-case toggle box (replace row): replacements
                        adopt the case shape of each match (see above)
    ⇉                   Replace All icon box — asks for confirmation first
    Files to Include    comma-separated globs (`*.lua`) or paths (`src`,
                        searched recursively as `src/**`). Empty = all files.

6. API                                                  *vscode-search-replace-api*

                                                        *vscode-search-replace-open()*
require("vscode-search-replace").open({opts})
    Opens (or toggles closed) the float. `opts` fields:
      file      = true   → search the current file only
      word      = true   → prefill the pattern from the visual selection
                          (normal mode: word under cursor) and search
      pattern   = "..."  → prefill with a literal pattern, searched
      other fields are merged as initial search params
    Calling with the float open closes it.

8. Troubleshooting                          *vscode-search-replace-troubleshooting*

:checkhealth vscode-search-replace                  *:checkhealth*
    Reports Neovim version and ripgrep availability.

Common issues: ~
    - "searches will fail" in checkhealth → install `rg`.
    - Tree icons look wrong → install a Nerd Font.
    - `<Esc>` seems to need two presses → expected: the first leaves insert
      mode in the focused input, the second closes the float.
    - `ab` matches nothing → whole-word requires the match to start and end
      on keyword characters, like `rg --word-regexp`.
